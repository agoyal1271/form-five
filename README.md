# Form Five

A private, browser-based five-day training companion with short movement loops, form cues, workout completion tracking, and an editable profile.

## Run locally on macOS

Double-click `start-local.command`, or run:

```bash
./start-local.command
```

The app opens at [http://localhost:4173](http://localhost:4173). Press `Ctrl+C` in the Terminal window to stop it.

No installation or account is required. Profile and completion data are saved locally in the browser.

## Manual start

```bash
python3 -m http.server 4173 --directory dist
```
